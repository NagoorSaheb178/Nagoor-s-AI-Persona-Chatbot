# Project: Second Brain - AI Knowledge Management System

**Repository:** Second Brain – AI Powered Knowledge Management
**Tagline:** Built with ❤️ for thinkers and innovators.

Second Brain is a sophisticated, high-end knowledge management application designed to help users capture, organize, and synthesize knowledge using the power of Artificial Intelligence.

## Key Features
- **Cinematic Landing Page**: A premium, atmospheric entrance featuring GSAP animations and 100% transparent UI.
- **Intelligent Knowledge Feed**: Capture notes, links, and insights with automatic AI-powered summarization and tagging.
- **Connectivity Graph**: Visualize the relationships between your thoughts with an interactive semantic network (knowledge graph).
- **AI Brain Assistant**: Chat directly with your knowledge base. Ask questions, find facts, and discover hidden connections.
- **Developer-First API**: Expose your brain's intelligence via a public API for integrations.
- **Semantic Search**: Find any note or idea through natural language queries.

## Technology Stack
- **Frontend**: Next.js 15, React 19, Tailwind CSS
- **Animations**: GSAP, Framer Motion
- **Database**: MongoDB (via Mongoose)
- **AI**: Gemini API for AI Chat & Summarization
- **Styling**: Vanilla CSS + Tailwind for a bespoke, premium aesthetic.

## Problem Solved
Information overload is a modern epidemic. Second Brain acts as an external cognitive system — capturing ideas the moment they occur, intelligently organizing them, and surfacing the right information at the right time using AI.

## Role
Nagoor designed and built the full-stack application, implementing LLM-based summarization, semantic search using RAG pipelines, the contextual chat interface, and the interactive knowledge graph visualization.
