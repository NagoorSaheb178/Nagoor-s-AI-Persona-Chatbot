# Project: VeriCite AI - Hallucination Citation Verifier

**Repository:** AI Hallucination Citation Verifier
**Tagline:** The Future of Trustable Intelligence.

VeriCite AI creates an immutable layer of truth by verifying every claim and citation in AI-generated text against global research databases using the Puter.js cloud engine.

## Key Features
- **Real-time Grounding**: Instantly validates AI-generated text against verifiable sources.
- **Citation Audit**: Detects "hallucinated" citations and verifies author, journal, and existence.
- **Trust Metrics**: Visualizes the reliability of content with a Trust Score and detailed analytics.
- **High Performance**: Optimized with gpt-4o-mini via Puter.js for rapid response times.
- **Mobile Optimised**: Fully responsive design that works seamlessly on all devices.
- **Visual Confidence**: Emoji-based status animations during verification.

## Technology Stack
- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS
- **AI Engine**: Puter.js V2 (Cloud-based AI)
- **Visualization**: D3.js (Trust Gauge)

## Problem Solved
This project addresses one of the most critical issues in AI adoption — hallucination. LLMs frequently generate plausible-sounding but factually incorrect claims and citations. VeriCite AI provides a layer of verification to make AI outputs trustworthy and accountable.
